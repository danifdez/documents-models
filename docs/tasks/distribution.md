# Distribution of a field

Distribution analysis shows how values in one dataset field are spread or repeated.

## Numeric fields

Numeric values are divided into histogram ranges. The number of ranges can be selected or chosen automatically.

The result includes total, non-empty, and empty counts together with mean, median, standard deviation, minimum, maximum, lower and upper quartiles, skewness, and kurtosis.

## Text and categorical fields

Documents returns a bar chart of the 30 most frequent values and reports how many unique values were found. Total, non-empty, and empty counts are also included.

Both results include chart-ready values and the identity and display name of the analyzed field.
