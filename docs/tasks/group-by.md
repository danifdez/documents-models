# Group and aggregate

This analysis compares a numeric measure across the categories of another field. It can answer questions such as “What is the average salary by department?” or “What is total revenue by country?”

## Choices

Select:

- the categorical field that defines the groups;
- the numeric field to measure;
- mean, sum, count, minimum, maximum, or median as the aggregation. Mean is the default.

## Result

Documents returns one value for each group, sorted from highest to lowest. The same values are prepared for a bar chart and a table. The result also reports the number of groups and records considered.
