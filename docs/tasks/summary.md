# Dataset summary

The summary provides a quick overview of every field in a dataset without requiring additional choices.

## Result by field type

| Field type | Included information |
|---|---|
| Numeric | Mean, median, standard deviation, minimum, and maximum. |
| Text or category | Unique-value count and the most frequent value. |
| Date | Earliest and latest date. |

Every field also reports total, non-empty, and empty counts, plus the percentage of empty values.

The result includes the dataset's total record and field counts and is formatted as a table rather than a chart.
