# Time series

Time-series analysis shows how a numeric value changes over regular periods.

## Choices

Select:

- a date field for the time axis;
- a numeric field to follow;
- monthly, quarterly, or yearly grouping. Monthly is the default.

## Result

Documents groups records into the selected periods and calculates the average numeric value for each period. The result is prepared as both a line chart and a table.

A trend value summarizes the overall direction: positive means the measure generally increases over time, while negative means it generally decreases. It is a simple linear tendency and may not describe seasonal or irregular changes.
