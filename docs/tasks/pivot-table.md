# Pivot table

A pivot table cross-tabulates two categorical fields to show how their values occur together.

## Choices

Select:

- the field used for rows;
- the field used for columns;
- optionally, a numeric field to aggregate;
- count, mean, sum, minimum, maximum, or median as the calculation.

If no numeric value field is selected, Documents counts records. Count is the default calculation.

## Result

Each cell contains the calculation for one row-and-column combination. Documents also provides row totals, column totals, a grand total, and the field names used.

The same matrix is prepared for a table and a stacked bar chart. The summary reports the number of row and column categories, total records, and the selected calculation.
